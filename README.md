# maxi-yatzy-triple-solo
A solo version of maxi yatzy, in Chinese. Triple mode supported. 
# Maxi Yatzy 游戏规则

Maxi Yatzy 是经典骰子游戏 Yatzy 的变体，使用 **6 个骰子**，包含 **20 种计分组合**。游戏目标是在所有计分格填满后获得尽可能高的总分。

---

## 一、基本流程

- 游戏共进行 **20 个回合**（三倍模式下为 60 个回合）。
- 每个回合：
  1. 投掷 6 个骰子。
  2. 投掷后，可以选择保留任意数量的骰子，然后重投其余骰子。
  3. 每个回合开始时会获得 **2 次重投机会**，未用完的机会可以累积到后续回合使用。
  4. 重投后（或直接投掷后），选择一个尚未填写的计分格填入分数。
  5. 每个计分格只能填写一次。
- 如果某个计分格的条件不满足，玩家也可以选择该格，**得 0 分**。

---

## 二、计分表

计分表分为 **上区** 和 **下区**，共 20 个组合。

### 上区（Upper Section）

| 组合 | 说明 | 得分 |
| :--- | :--- | :--- |
| 一点 (Ones) | 所有显示为 1 的骰子点数之和 | 总和 |
| 二点 (Twos) | 所有显示为 2 的骰子点数之和 | 总和 |
| 三点 (Threes) | 所有显示为 3 的骰子点数之和 | 总和 |
| 四点 (Fours) | 所有显示为 4 的骰子点数之和 | 总和 |
| 五点 (Fives) | 所有显示为 5 的骰子点数之和 | 总和 |
| 六点 (Sixes) | 所有显示为 6 的骰子点数之和 | 总和 |

**上区奖励**：  
如果上区 6 项的原始分数总和达到或超过 **84 分**，额外获得 **100 分**奖励。

---

### 下区（Lower Section）

| 组合 | 说明 | 得分 |
| :--- | :--- | :--- |
| 一对 (One Pair) | 两个点数相同的骰子 | 该对骰子点数之和 |
| 两对 (Two Pairs) | 两个不同点数的对子 | 两对骰子点数之和 |
| 三对 (Three Pairs) | 三个不同点数的对子 | 所有骰子点数之和 |
| 三条 (Three of a Kind) | 三个点数相同的骰子 | 这三个骰子点数之和 |
| 四条 (Four of a Kind) | 四个点数相同的骰子 | 这四个骰子点数之和 |
| 五条 (Five of a Kind) | 五个点数相同的骰子 | 这五个骰子点数之和 |
| 小顺子 (Small Straight) | 骰子组合为 1-2-3-4-5 | 固定 15 分 |
| 大顺子 (Large Straight) | 骰子组合为 2-3-4-5-6 | 固定 20 分 |
| 全顺子 (Full Straight) | 骰子组合为 1-2-3-4-5-6 | 固定 21 分 |
| 葫芦 (Full House) | 一个“三条”加一个“一对”（点数需不同） | 只计组成葫芦的五个骰子之和 |
| 城堡 (Castle/Villa) | 两个不同的“三条” | 所有骰子点数之和 |
| 塔 (Tower) | 一个“四条”加一个“一对”（点数需不同） | 所有骰子点数之和 |
| 机会 (Chance) | 任意组合 | 所有骰子点数之和 |
| **Maxi Yatzy** | **六个骰子点数全部相同** | **100 分** |

> **葫芦说明**：葫芦只考虑五个骰子，第六个骰子可以是任意点数，不影响葫芦的成立，得分也只算组成葫芦的五个骰子。

## 三、三倍模式（Triple Mode）

三倍模式是为有经验的玩家设计的进阶玩法，核心变化如下：

- 游戏同时使用 **三列独立的计分表**。
- 玩家需要在三列中分别完成所有 20 种组合的计分，共 60 个计分格。
- 三列分数倍率分别为：
  - 第一列：×1
  - 第二列：×2
  - 第三列：×3
- 上区奖励也按列倍率翻倍。奖励判定门槛（84 分）以该列乘倍率之前的上区原始分计算。
- 每回合投骰后，玩家可以自由选择三列中任意一列的一个空计分格填入分数。
- 重投机会池由三列共享，每回合开始获得 2 次，未用完可累积。

---

## 四、游戏结束

- 普通模式：填满 20 个计分格后结束。
- 三倍模式：填满 60 个计分格后结束。
- 最终总分 = 所有列总分之和。
- 玩家可以点击“重玩一局”重新开始。
